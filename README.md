## 泰国住宅 IP 的判断标准：ASN 归属和 IP 类型

TikTok 的风控把 IP 归属和 IP 类型当作关键维度。你在泰国区用一个机房 IP 发视频，后台看到的 ASN 属于某家云服务商，归属地也不是泰国运营商，这种组合本身就是高危信号，轻则限流，重则封号。住宅 IP 的价值在于它的“户口本”写的是家庭宽带运营商，平台判定你是一个在泰国本地家庭网络里正常使用 App 的人，风控阈值自然低一些。

## VPS 和住宅代理不是一回事

搜“泰国住宅 IP”的人有一半其实需要的不是 VPS。两者的差别在于买的是什么：住宅代理买的是出口 IP，VPS 买的是一台位于当地的机器。

只做浏览器多开、数据采集、少量账号的日常操作，代理更轻，按 IP 或流量计费，成本低。但做直播推流、长期挂机、跑自动化脚本，代理就不合适了，你要的是一个能装环境、能常驻运行、带宽稳定的机器。另外，不少代理服务商在购买页明确写着“所有代理服务需要设备在境外网络环境下使用，境外网络环境需客户自行配置”，也就是说你还得先解决本地网络这一层。VPS 没有这个问题，买完连上就能用。
